一、这是什么

一套给中小学微课、MG 动画、互动网页用的分层矢量场景。每个场景 1920×1080，全部由程序绘制（不是 AI 位图），放大不糊、可改色、可逐层动起来。场景里不放人物，角色（真人抠像、GIF、矢量人、3D）按你的风格另外叠加。

文件用途
MG场景图库.html浏览、搜索、预览入场动画、换配色、看安全区、下载 SVG
svg/s001.svg …场景源文件，可直接放进网页、PPT、剪映、AE、Illustrator
png/s001.png …1920×1080 静帧，直接当背景用
scenes.json场景目录：编号、名称、分类、适用学科、图层、角色站位、配色变量
mgscene.js网页运行时：入场、循环、换配色、定格
export_mp4.py把任意场景的入场动画导出成 MP4（视频剪辑用）
src/场景生成代码（core.py 工具库 + scenes_*.py），用来改场景或新增场景

二、最快用法

做 PPT / 剪映：直接用 png/ 里的图当背景；要动效就用 export_mp4.py 导出 4 秒入场视频，放在开头，后面接静帧。

做互动网页：

<div id="bg"><!-- 把 svg/s001.svg 的内容粘贴到这里 --></div>
<script src="mgscene.js"></script>
<script>
  const svg = document.querySelector('#bg svg');
  MGScene.play(svg);            // 逐层入场 + 循环动效
  MGScene.theme(svg, 'dusk');   // 换配色：original cool warm dusk night soft
</script>

做视频（逐帧渲染）：

python3 export_mp4.py s001 4 out.mp4          # 场景编号 时长(秒) 输出
python3 export_mp4.py s032 6 clock.mp4 --theme night

三、每个场景里有什么

图层：每个场景拆成 8–14 层（天空、远景、建筑、地面、道具、光效……），每层带入场方式（升起、落下、弹出、长出、左右滑入、淡入、推近）和出场时间，部分层带循环（云漂移、树摇摆、灯呼吸、钟摆摆动、萤火闪烁）。在 SVG 里是 <g class="layer" data-enter="rise" data-delay="0.45" data-loop="sway">，可以直接改数字调节奏。

配色变量：所有颜色写在 SVG 根节点的 CSS 变量里（如 --wall1、--board）。改一个变量，整场同色元素一起变；也可以用 6 套预设一键换。

安全区：scenes.json 的 stand 给出角色脚踩的地面线和可站范围，subtitle 给出字幕区（底部居中）。在图库里点「安全区」能看到。

四、制作建议

1. 一集换 3–5 个场景，相邻镜头不要用同一分类，观感更新鲜。
2. 角色脚底对齐 ground_y，人物高度约为画面高度的 45%–55%。
3. 讲知识点时用「黄昏」「柔和」配色压低背景，前景卡片更突出；夜晚配色适合睡眠、星空类主题。
4. 场景里尽量不写字（只有极少数装饰字），标题、标签、字幕由你的课件模板加。
5. 需要新场景时，在 src/scenes_*.py 里复制一个函数改，运行 python3 render.py 自动生成 SVG、PNG 和目录，再运行 python3 build_gallery.py 更新图库。

五、环境

浏览器打开即可使用图库和网页运行时。导出视频和重新生成需要 Python 3、playwright（Chromium）和 ffmpeg：pip install playwright && playwright install chromium。
